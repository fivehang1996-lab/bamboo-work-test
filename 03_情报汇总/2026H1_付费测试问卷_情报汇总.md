## 五、摘录方法论（已验证可行）

```
1. 找到B站问卷填写视频 → 获取BV号
2. yt-dlp -f "30032+30280" 下载480P视频
3. opencv提取帧(每1.5秒) → PNG格式
4. easyocr.Reader(['ch_sim','en']) 逐帧OCR
5. 人工校对+去重 → 按板块结构化
6. 输出Excel(题目+题型+选项+来源)
```

**工具链**: yt-dlp + opencv-python + easyocr + openpyxl
**单视频耗时**: 下载2分钟 + 帧提取1分钟 + OCR约10-15分钟(CPU) + 人工校对15分钟
