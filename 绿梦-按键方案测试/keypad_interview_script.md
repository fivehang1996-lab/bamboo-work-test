# 按键方案街访 — 研究员话术脚本

## 项目: 《绿梦：时空之声》默认按键方案玩家测试
## 测试形式: 大学街访
## 总时长: 约12分钟/人

---

# 阶段一: 盲测初体验(10分钟)

---

### 1.1 分配方案 | 10秒

| 项目 | 内容 |
|------|------|
| **话术** | (无需说话) |
| **动作** | 在记录表上填写玩家编号(P001-P060), 按随机分配表确定方案A/B/C, 在手机上设置对应的按键方案后递给玩家 |
| **记录** | 分配方案编号(A/B/C) |

**注意事项:**
- 手机提前准备好三套方案的快捷切换方式
- 玩家看不到方案代号
- 不提及[方案][按键][测试目标]等词

---

### 1.2 介绍按键说明 | 30秒

| 项目 | 内容 |
|------|------|
| **话术** | "同学你好! 我们正在做一个游戏按键的体验测试。这里有一张按键说明卡, 标注了每个按钮的功能, 你可以先看一眼, 了解一下哪个键是做什么的。如果有不清楚的, 可以问我。" |
| **动作** | 发放按键说明卡(提前印刷好, A4硬纸板, 标注各按键位置和功能) |
| **记录** | 玩家提出的疑问内容(如有) |

**注意事项:**
- 只解释"哪个键是干什么的", 不解释"这个方案的设计逻辑"
- 如果玩家问[这个按键可以改吗?][还有其他布局吗?] → "目前就是这个设置, 请先按这个玩。"
- 玩家问第一个问题时记录: 「玩家主动询问按键可改性」——这是对默认方案不满的早期信号

**禁止话术:**
| 禁止 | 原因 |
|------|------|
| "这个方案是XX设计的" | 引入权威偏误 |
| "这套按键很合理吧?" | 引导性 |
| "慢慢来, 不着急" | 给玩家暗示"可能比较难" |

---

### 1.3 完成指定章节 | 0-5分钟

| 项目 | 内容 |
|------|------|
| **话术** | "好的, 现在请用这个按键设置, 完成这两个关卡——先跑酷, 再战斗。正常玩就行, 不用着急通关, 我们就是想看看自然状态下的操作感受。" |
| **动作** | 启动游戏 → 计时开始 → 全程安静观察 |
| **记录** | (见下方记录清单) |

**关卡说明:**
- **材料副本A(跑酷):** 含基础移动+跳跃+平台跨越的固定路线
- **材料副本B(战斗):** 含基本攻击+技能释放+闪避的固定战斗片段

**研究员观察记录清单:**

| 观察项 | 记录方式 | 示例 |
|--------|---------|------|
| 计时 | 从进入副本到完成/放弃的时间 | 3分22秒 |
| 操作困难 | 何处停顿/反复尝试/方向偏离 | "跑酷第二个平台跳了3次才上去" |
| 手指位置是否有异常 | 拇指跑偏出摇杆区/频繁看按键/手指遮挡 | "拇指与屏幕下边缘反复摩擦" |
| 是否主动打开设置页 | 是/否 | 如果[是], 追问: "你想改什么?" |
| 表情/叹气/皱眉 | 发生在哪个操作场景 | "战斗切人时明显皱眉" |
| 是否放弃/跳过 | 哪个关卡/哪个节点 | "跑酷第三次坠落后放弃, 直接切到战斗" |

**注意事项:**
- 玩家卡住超过 30 秒且明显烦躁 → 轻声说"可以跳过", 并记录跳过点和原因
- 玩家问"这个怎么操作?" → 不回答, 说"你试试看"
- 不提示任何操作技巧
- 不做任何评价(不说[不错][厉害][没关系])

**禁止话术:**
| 禁止 | 原因 |
|------|------|
| "往那边跳" | 操作指导 |
| "这个BOSS有点难对吧" | 暗示难度 |
| "你用技能打啊" | 引导操作 |
| "没事, 很多人都过不去" | 安慰 = 暗示"这里有问题" |

---

# 阶段二: 对比选择(2分钟)

---

### 2.1 告知方案 | 10秒

| 项目 | 内容 |
|------|------|
| **话术** | "好的, 刚才您用的是方案__(填代号)。实际上还有另外两套不同的按键方案, 我帮您分别调出来, 您可以试试手感。" |
| **动作** | 研究员帮切换到另外两套方案的快捷入口, 展示给玩家看怎么切 |
| **记录** | (无) |

**注意事项:**
- 不评价任何方案: 不说[这套更好][这套很多人选]
- 切换操作要快(研究员提前练熟)
- 玩家可能会问[刚才那套是哪个?] → 如实告知代号即可

---

### 2.2 切换体验 | 0-5分钟

| 项目 | 内容 |
|------|------|
| **话术** | "您可以用这两套方案重新玩一下刚才的关卡, 也可以只试一段。随意试试手感就行。" |
| **动作** | 让玩家自由体验, 不催促 |
| **记录** | (见下方) |

**记录清单:**

| 观察项 | 记录方式 |
|--------|---------|
| 先切到哪套? | B还是C |
| 每套方案体验了多长时间? | 秒 |
| 每套方案的开口反馈 | 逐字记录(如[这个别扭][这个顺][摇杆位置不习惯]) |
| 是否在方案之间来回切? | 几次 |
| 是否想回到原方案? | 是/否 |

**注意事项:**
- 不做引导评价, 只做录音记录 + 关键词速记
- 玩家说任何评价都只点头, 不附和
- 如果玩家问[你觉得哪个好?] → "等您选完我再说"

---

### 2.3 最终选择 | 20秒

| 项目 | 内容 |
|------|------|
| **话术** | "现在假设您是第一次玩这个游戏的新玩家。A、B、C 三套方案里面, 您觉得哪一套最应该作为默认的按键方案?"(玩家回答后)"为什么选这套?" |
| **动作** | 指向三张方案卡片(A/B/C标识), 让玩家指或说 |
| **记录** | 选择结果 + 逐字理由(录音 + 速记) |

**注意事项:**
- 强调[新手视角], 不是问[你自己最喜欢哪个]
- 如果玩家犹豫, 等待, 不要催
- 如果玩家说[其实差不多] → 追问[如果非要选一个呢?]
- 理由逐字记录, 不要用自己的话概括(至少在这一步)

---

### 2.4 补充选择 | 10秒

| 项目 | 内容 |
|------|------|
| **话术** | "如果有个朋友用不惯默认的这套, 您会建议他切到哪套?" |
| **动作** | 指向另外两张卡片 |
| **记录** | 补充选择结果 |

---

# 阶段三: 材料填写(3分钟)

---

### 3.3 量表填写(K-SUS) | 2分钟

| 项目 | 内容 |
|------|------|
| **话术** | "最后请您填一份反馈表。不需要想太多, 按第一感觉勾就行。这是针对您最开始用的那套方案(方案X)的反馈。" |
| **动作** | 递给玩家平板或纸质量表, K-SUS 共10题 |
| **记录** | Q1-Q10全部10题得分 |

**K-SUS量表(5点李克特):**

| 题号 | 题目 | 非常不同意(1) ... 非常同意(5) |
|------|------|------|
| Q1 | 我觉得这组按键方案用起来很顺手, 不需要额外适应。 | 1 - 2 - 3 - 4 - 5 |
| Q2 | 我觉得左边摇杆的控制范围不清晰, 经常不知道手指放在哪里。 | 1 - 2 - 3 - 4 - 5 |
| Q3 | 我觉得右侧按键的布局和大小是合理的, 不太会误触。 | 1 - 2 - 3 - 4 - 5 |
| Q4 | 我觉得按键响应有延迟, 或者需要较大力气按下去才有反应。 | 1 - 2 - 3 - 4 - 5 |
| Q5 | 我可以流畅地完成二段跳、冲刺、空中转向等操作。 | 1 - 2 - 3 - 4 - 5 |
| Q6 | 我经常会出现二段跳了仍然跳不上平台的情况。 | 1 - 2 - 3 - 4 - 5 |
| Q7 | 我觉得角色做出的动作与我的操作意图是一致的, 没有偏差感。 | 1 - 2 - 3 - 4 - 5 |
| Q8 | 我觉得镜头视角影响了我的操作判断, 经常看不清楚该往哪跳或敌人在哪。 | 1 - 2 - 3 - 4 - 5 |
| Q9 | 我觉得目前的视角可以让我在探索和战斗中获取到足够信息。 | 1 - 2 - 3 - 4 - 5 |
| Q10 | 我觉得这个按键方案对于第一次玩的人来说, 上手会比较费劲。 | 1 - 2 - 3 - 4 - 5 |

**注意事项:**
- 提醒玩家: [这些题目是针对您最开始用的那套方案(方案X)的, 不是针对后面试的那两套。]
- 不解释题目含义(避免引导)
- 玩家如果对某道题有疑问 → "按您自己的理解勾就行"
- 填完后快速扫一眼, 确保没有漏填

---

### 收尾 | 10秒

| 项目 | 内容 |
|------|------|
| **话术** | "好的, 全部完成了! 感谢参与! (递奶茶/红包) 如果对游戏感兴趣可以关注我们的公测。" |
| **动作** | 确认所有数据记录完整, 感谢玩家 |

# 附录: 全程禁止话术总结

| 禁止说 | 原因 | 正确替代 |
|--------|------|---------|
| "你觉得哪套更好?" | 引导性太强 | "你觉得哪套应该作为默认?" |
| "这个方案是XX设计的/这个是改过的" | 权威偏误 | 不评价方案来源 |
| "大部分人都选了X" | 从众效应 | 不做任何统计透露 |
| "这个按键太小了是吧?" | 诱导性提问 | "您在操作中遇到什么难点?" |
| "玩得怎么样?" | 太笼统 | "在操作上有什么不舒服的地方?" |
| "没关系, 慢慢来" | 暗示操作有难度 | (安静等待) |
| "你试试用技能" | 操作指导 | (记录玩家困惑, 不做提示) |
