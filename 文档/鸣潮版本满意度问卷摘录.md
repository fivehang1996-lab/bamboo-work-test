## 三、题型和维度总结

### 问卷结构模式

```
┌─────────────────────────────────────┐
│ ① 人口属性（性别/年龄/职业/城市）    │
│ ② 游戏行为（频率/时长/平台/入坑时间）│
│ ③ 获客渠道（怎么知道这游戏的）       │
│ ④ 满意度评分（总体 + 分维度矩阵）    │
│ ⑤ 偏好与期待（内容/角色/玩法/皮肤）  │
│ ⑥ 情感与动机（NPS/情绪/心理需求）    │
│ ⑦ 竞品与兴趣（还玩什么游戏）         │
│ ⑧ 联系方式（手机/邮箱）+ 开放建议    │
└─────────────────────────────────────┘
```

### 鸣潮特色题型

| 题型 | 使用场景 |
|------|----------|
| 10 分制维度打分 | 版本综合满意度 |
| 李克特 1-5 量表 | 角色热爱度、服务体验 |
| 矩阵量表 | 服务评价（多维度同时打分） |
| 角色排序题 | 角色偏好优先级 |
| 皮肤主题多选 | 商业化方向调研 |
| 随机化投放（7 种变体） | 避免问卷疲劳、覆盖更多维度 |
| 开放建议框 | 版本末的定性反馈收集 |

## 四、对绿梦问卷的参考建议

1. **加版本专项打分矩阵**：借鉴 2.0 的 8 维度，适配绿梦做 5-6 维度的版本评分（如：角色设计/战斗手感/关卡趣味性/剧情代入感/美术风格/音乐音效）
2. **引入 XP 偏好题**：了解玩家喜欢什么类型的角色、什么风格，为后续角色制作提供方向
3. **皮肤/商业化调研**：问皮肤主题偏好和购买决策因素，为变现做铺垫
4. **随机化投放**：如果问卷量大，可以准备 2-3 套变体随机投放，减少玩家倦怠
5. **用 NPS 题收尾**：「你会把这款游戏推荐给朋友吗？」是行业通用的玩家忠诚度指标
