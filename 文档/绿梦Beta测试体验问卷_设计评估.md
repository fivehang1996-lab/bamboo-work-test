## 一、问卷概览

| 指标 | |
|------|------|
| 总题数 | **20 题**（19 必填 + 1 开放选填） |
| 预估耗时 | 3-4 分钟（开头说明称"约5分钟"，基本吻合） |
| 定位判断 | **首份/筛选型问卷**——画像 + 游戏经历 + 社媒渠道为主，体验评价为辅 |

## 二、题目结构逐块分析

### 块1：入口（Q1）✅ 无问题

```
Q1 同意书 → 标准操作，没问题
```

### 块2：平台与设备（Q2-Q3）✅ 良好

```
Q2 单选：移动端 / PC端 / 双端
Q3 条件显示：Q2选PC或双端时才出现
```

**亮点**：Q2→Q3 的跳转逻辑是这份问卷里唯一一处条件跳转，设计正确。
**小瑕疵**：Q3的附属说明放在选项下面容易被忽略。

### 块3：整体评价（Q4）⚠️ 位置偏前

```
Q4 单选五级：远不如 → 远好于（竞品对标式提问）
```

**问题**：Q4 放在问卷第 4 位，此时玩家还没回顾自己的游戏经历（Q5-Q8）和习性（Q10-11）。先问整体评价后问游戏背景，可能导致：

- 玩家答 Q4 时缺乏参照系（"和我玩的游戏比"——我还不知道你玩过什么）
- 后续 Q5-Q8 的游戏经历回忆可能让玩家重新评估 Q4 的答案，但已经无法修改

**建议**：Q4 移到 Q8 之后（游戏经历块结束），或至少移到 Q11（时长+消费）之后。

---

### 块4：游戏经历（Q5-Q8）⚠️ 选项过多、结构可优化

```
Q5 多选 17+1 选项：深入体验过的手机游戏类型
Q6 多选 12+1 选项：深入体验过的手机游戏产品
Q7 多选 14+1 选项：深入体验过的PC/主机游戏类型
Q8 多选 15+1 选项：深入体验过的PC/主机游戏产品
```

**设计合理之处**：
- 类型→产品的递进逻辑正确（先类型后具体）
- 手端和PC端分两套题目，覆盖完整
- Q6 的 13 款产品聚焦横版动作+银恶赛道，竞品圈层精准
- 均有"以上都没有"选项

**问题**：

1. **Q5 和 Q7 对纯一端玩家是冗余**：纯移动端玩家也要看 15 个 PC/主机类型的选项。虽然可以选"以上都没有"，但视觉疲劳是真实的。

   > **建议**：Q2 选"移动端"的玩家跳过 Q7-Q8（PC/主机块），同理纯 PC 端玩家跳过 Q5-Q6。目前问卷**没有做这个跳转**。

2. **选项密度过高**：连续 4 道 12-18 选项的多选题，认知负荷大。每个选项平均 8-10 个字还带括号例子。

3. **Q5 选项排序无优先级**：17 个游戏类型按什么逻辑排列？建议将与绿梦最相关的类型（横版动作、开放世界、卡牌RPG、动作类、银恶类）往前排。

---

### 块5：长期动力排序（Q9）⚠️ 位置尴尬

```
Q9 排序题：从 10 项中选 4 项并按优先级排序
```

**题目本身设计优秀**：10 个动力维度覆盖全面（剧情/操作/挑战/强度/策略/成就/规划/解谜/探索/情感），选 4 排序在认知负荷和区分度之间取得了好平衡。

**但位置有问题**：Q9 插在游戏经历（Q5-8）和游戏习惯（Q10-11）之间，打断了自然流程。

> **建议**：移到 Q11 之后，和社媒块前后交换。逻辑链应该是：我玩过什么 → 我花多少时间/钱 → 我为什么玩 → 我通过什么渠道获取信息。

---

### 块6：游戏习惯（Q10-Q11）✅ 标准题，无问题

```
Q10 单选：每周游戏时长（6段）
Q11 单选：月均消费（7段）
```

- 分段合理，覆盖全面
- Q10 从 <5h 到 40h+，Q11 从 0 到 2000+
- "几乎不花钱"比"0元"表达更好

---

### 块7：社媒与渠道（Q12-Q15）✅ 整体优秀

```
Q12 多选限4：新游戏信息渠道（15选项）
Q13 多选限3：最常用社媒平台（12选项）
Q14 多选限3：游戏内容偏好（10选项）
Q15 多选限3：线下活动偏好（9选项）
```

**亮点**：
- Q12 作为核心题，15 个渠道覆盖 B站/抖音/TapTap/NGA/小红书/海外平台等，非常全面
- Q12→Q13 形成"渠道广度→使用深度"的递进
- Q14 补充了"什么形式的内容"（视频/图文/直播/二创）
- Q15 线下活动触及运营场景（漫展/快闪/联名/试玩会）
- 每道题有数量上限，防止全选滥填

**小问题**：

- Q12 限 4 可能偏紧：重度社媒用户可能同时用 5-6 个渠道获取游戏信息。建议放宽到 5 项。
- Q13 选项有"好游快爆"但无"米游社"：好游快爆体量小于米游社，后者对二次元品类更重要。
- Q14 和 Q15 之间没有"几乎不参与"的互斥逻辑：如果 Q14 选了"不怎么看游戏相关内容"，理论上应该跳过 Q15。但问卷星可能不支持跨题跳转。

---

### 块8：人口属性（Q16-Q18）✅ 标准题

```
Q16 单选：性别（男/女/不愿透露）
Q17 单选：年龄（6段）
Q18 填空：常住城市
```

**无问题但不完美**：
- 缺"职业"题。职业对消费力和游戏时间有强解释力，建议补上。
- Q18 用填空而非下拉城市选择器，数据清洗成本高。建议改用省级/城市层级单选。

---

### 块9：NPS + 开放（Q19-Q20）✅ 收尾标准

```
Q19 NPS 0-10：推荐意愿
Q20 填空选填：开放意见
```

位置合理——NPS 放在社媒和人口之后、开放题之前。Q20 选填降低最后一道的完成门槛。

## 三、跳转逻辑审计

| 跳转点 | 当前状态 | 应该怎样 | 严重度 |
|--------|----------|----------|:--:|
| Q2→Q3 | ✅ 已实现 | PC端才显示Q3 | — |
| Q2→Q5/Q6 | ❌ 未实现 | 纯PC端玩家应跳过手机游戏类型/产品 | 中 |
| Q2→Q7/Q8 | ❌ 未实现 | 纯移动端玩家应跳过PC/主机类型/产品 | 中 |
| Q14→Q15 | ❌ 未实现 | 选"不怎么看游戏内容"应跳过线下活动 | 低 |

**核心问题**：这份问卷对纯一端玩家（只在手机玩/只在PC玩）多问了 2 道完全不相关的题（Q5-6 或 Q7-8）。如果移动端玩家占多数，这就是普遍性的冗余。

## 四、题目顺序评估

### 当前顺序

```
入口 → 平台 → 整体评价 → 游戏经历(类型/产品×4) → 动力排序
→ 时长/消费 → 社媒渠道(×4) → 人口(×3) → NPS → 开放
```

### 问题

1. **Q4 整体评价插在平台和游戏经历之间**——先问结论再问依据
2. **Q9 动力排序切断游戏经历块和习惯块**——同属"玩家画像"却被拆散
3. **人口属性在倒数位置**——对于首份问卷可以接受（先内容后隐私），但没有职业题是缺憾

### 建议顺序

```
入口 → 平台+设备 → 游戏经历(类型+产品) → 时长+消费
→ 动力排序 → 整体评价 → 社媒渠道 → 人口(含职业) → NPS → 开放
```

## 五、题型与量表质量

### 做得好的

| 题目 | 评价 |
|------|------|
| Q4 | 用竞品对标代替抽象满意度，有区分度 |
| Q9 | 选4排序——在"单选打不出差异"和"全排太累"之间找到了平衡 |
| Q12-Q15 | 多选限额防止极端填答 |
| Q19 | 标准 NPS 0-10 双端点标签 |
| Q20 | 非必填，不强迫 |

### 需改进的

| 问题 | 说明 |
|------|------|
| Q5 选项17个太多 | 建议按品类分组用分页展示，或用搜索式多选 |
| Q18 填空城市 | 数据清洗噩梦。改用下拉或城市层级单选 |
| 缺职业题 | 对消费和时间的解释比年龄更直接 |
| Q4 选项表述 | "远不如我玩的游戏"——参照系是"我玩的所有游戏的平均"还是"我玩的最好的游戏"？玩家理解会不一致 |

## 六、可选矩阵 / 重复测题

| 检查项 | 结果 |
|--------|------|
| 内容重复 | Q5（游戏类型）和 Q7（PC类型）结构镜像，非重复，各测一端 ✅ |
| Q12（渠道）和 Q13（最常用平台） | 非重复——一个是"获取新游戏信息"一个是"日常使用"，场景不同 ✅ |
| Q9（动力排序）和问卷内容 | Q9 是此问卷中唯一一道动力题，无重复校验设计 ⚠️ |

Q9 没有互校题——Beta2.0 深度问卷里 Q31 和 Q39 做了量表+排序的双测校验，这份没有。考虑到这是短问卷，可以接受。

## 八、改进优先级

| 优先级 | 改什么 | 为什么 |
|:--:|------|------|
| **P0** | 加端侧跳转：纯移动端跳过 Q7/Q8，纯PC端跳过 Q5/Q6 | 消除每个纯一端玩家的 2 道无关题，直接影响完成率 |
| **P1** | Q4 移到 Q11 之后 | 先让玩家建立游戏经历的参照系，再问整体评价 |
| **P1** | Q9 移到 Q11 之后 | 游戏经历→习惯→动力的自然流 |
| **P2** | 补一道职业题（单选） | 画像更完整 |
| **P2** | Q18 改为城市层级单选 | 大幅降低数据清洗成本 |
| **P2** | Q12 放宽到限 5 项 | 15 个渠道限 4 偏紧 |
