> 2026-05-20 | 来源：Claude Code 官方文档 / Anthropic Platform / WebFetch

---

## 一、当前状态

你现在跑在 **deepseek-v4-pro** 上，这个模型不支持视觉（图片识别、截图分析都不行）。必须切换到 Claude 本家模型才能看图。

---

## 二、Claude Code 模型 alias 速查

Claude Code 用 alias 切换模型，不需要记完整模型 ID：

| Alias | Anthropic API 解析为 | 视觉能力 |
|-------|---------------------|:--:|
| `opus` | Claude Opus 4.7 | ✅ 最强 |
| `sonnet` | Claude Sonnet 4.6 | ✅ 支持 |
| `haiku` | Claude Haiku 4.5 | ✅ 支持（轻量） |
| `best` | 等同于 `opus` | ✅ 最强 |
| `opusplan` | Plan模式用Opus，执行用Sonnet | 混合 |

## 五、方案推荐

### 你的使用场景

游戏用研——经常需要看截图、问卷UI、Excel 表格图片、方案设计稿。

### 首选：Opus 4.7 `opus`

**理由**：
- 视觉准确率 98.5%，读截图/UI/表格几乎不出错
- 高分辨率支持（2576px），你发的设计稿截图不会被压缩降质
- 1M 上下文，长文档+多张图片一轮看完
- 目前视觉最强的 Claude 模型

**切换方式**：

```
/model opus
```

或者在 settings.json 里永久设：

```json
{ "model": "opus" }
```

### 备选：Sonnet 4.6 `sonnet`

**适用场景**：日常文字工作为主，偶尔看图。速度快、成本低。但视觉准确率只有 54.5%，复杂截图可能读错。

```
/model sonnet
```

### 不推荐：Haiku 4.5

视觉能力有但弱，适合简单文本提取，不适合设计稿/问卷截图这种精细任务。

## 六、快速操作

在当前 Claude Code 会话里直接敲：

```
/model opus
```

就会弹出模型选择器，选 Opus 即可立即切换。切换后新对话就能看图了。**注意：当前会话已经产生的对话历史不会自动迁移。**

想看自己当前用的什么模型，敲：

```
/status
```

---

## 七、Opus 4.7 额外建议

Opus 4.7 支持 `xhigh` effort level（默认就是这个），复杂视觉分析任务建议保持。如果想更深度推理可以调成 `max`：

```
/effort max
```

注意 `max` 仅对当前会话生效，不持久化。
